# Frontend 2D/3D

## Lệnh chạy
- `pnpm install`: Cài đặt dependencies.
- `pnpm dev`: Chạy dev server.
- `pnpm build`: Build source code.
- `pnpm preview`: Chạy bản build nội bộ.
- `pnpm lint`: Chạy ESLint.
- `pnpm typecheck`: Kiểm tra kiểu dữ liệu TypeScript.
- `pnpm test`: Chạy unit test.
- `pnpm e2e`: Chạy e2e test.
- `pnpm e2e:visual`: Chạy e2e test cập nhật snapshot.
- `pnpm storybook`: Chạy Storybook.
- `pnpm build-storybook`: Build Storybook.
